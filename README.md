# List Formatter

A simple web-based tool for formatting lists with various options.

## Features

- **Comma Formatting**: Convert a list of items into a comma-separated string
- **Quote Formatting**: Add single quotes around each item and separate with commas
- **Duplicate Removal**: Remove duplicate items from your list
- **Copy to Clipboard**: Easily copy the formatted output to your clipboard
- **Responsive Design**: Works on desktop and mobile devices

## Usage

1. Enter your list items in the input textarea (one item per line)
2. Choose your desired formatting option:
   - **Format with Commas**: Creates a comma-separated list
   - **Format with Quotes**: Adds single quotes around each item
   - **Remove Duplicates**: Removes duplicate items from your list
3. Copy the formatted output to your clipboard
